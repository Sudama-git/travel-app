# WANDER – Travel Discovery App

WANDER is a responsive React travel discovery application that helps users explore popular destinations, search for places, check real-time weather, use their current location, and save a favorite destination.

## Features

- 🔍 Search destinations by name, country, or continent
- 🌍 Browse popular travel destinations
- 🗺️ Filter destinations by continent
- ❤️ Save a favorite destination
- 📍 Detect the user's current location
- 🌤️ View real-time weather information
- 📱 Responsive design for desktop and mobile
- ☰ Mobile navigation menu
- ⚠️ Loading and error handling for weather data

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- OpenWeather API
- Browser Geolocation API
